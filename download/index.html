VibeDesk for Windows

Free and open source (MIT) · Windows 10/11 · uses your own Claude plan

Download for Windows All releases

  1. Run the installer

    Open VibeDesk-Setup-<version>.exe from your downloads. A short welcome tour sets everything up. After that you can start VibeDesk any time with Win + R → vibe.

  2. If Windows says “Windows protected your PC”

    Click More info, then Run anyway. The installer is not code-signed yet (certificates cost money every year), and SmartScreen also warns about apps that haven’t been downloaded often. It does not mean the file was flagged as malware.

  3. Claude Code missing? VibeDesk sets it up

    If Node.js or Claude Code aren’t installed, VibeDesk offers to install them on first start (Node.js via winget, Claude Code via the official installer script from claude.ai). You need a Claude Pro/Max subscription or an Anthropic API key: VibeDesk runs the normal claude command with your own plan.

Check the file (optional)

Compare the SHA256 checksum of your download with the one GitHub lists for this release:

Get-FileHash .\VibeDesk-Setup-<version>.exe -Algorithm SHA256
