Is VibeDesk made by Anthropic?

No. VibeDesk is an independent, unofficial open-source project. It runs the real Claude Code CLI that you install and log in to yourself.

What do I need?

Windows 10 or 11 (64-bit) and a Claude Pro or Max plan or an Anthropic API key. If Node.js or Claude Code are missing, VibeDesk offers to install them on first start.

Is it really free?

Yes. VibeDesk is free and open source under the MIT license. Claude usage is billed by Anthropic through your own plan, not by VibeDesk.

Windows says “Windows protected your PC”.

The installer is not code-signed, so SmartScreen may warn about it. Click More info, then Run anyway. To check the file, compare its SHA256 checksum with the one in the release notes.
