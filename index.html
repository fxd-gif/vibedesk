FAQ

Questions

Is VibeDesk made by Anthropic?

No. VibeDesk is an independent, unofficial project. It runs the real Claude Code CLI that you install yourself.

What do I need?

Windows 10 or 11, Claude Code installed, and a Claude Pro/Max plan or an API key. VibeDesk can install Git and the GitHub CLI for you with one click if you want them.

Is it really free?

Yes. VibeDesk is free and open source under the MIT license. Claude usage is billed by Anthropic through your own plan, not by VibeDesk.

Does it change my Claude Code settings?

No. VibeDesk does not touch your ~/.claude/settings.json or project settings. Sessions started in VibeDesk get a temporary settings file with its hooks, passed via --settings. Sessions you start elsewhere are not affected.

What stays on my PC?

Everything. Settings, stats and notes are stored locally; the brain lives in a .vibedesk folder inside your project. Phone access from outside your network only happens if you turn it on — then a Cloudflare tunnel is used, and pairing still needs the code from your screen.

Which languages does the app support?

The interface is German today. An English interface is coming with version 1.1.

Mac or Linux?

Not at the moment. VibeDesk is built for Windows 10 and 11.
