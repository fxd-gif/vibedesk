Built around your workflow

The work is moving. You shouldn't have to chase it.

When several Claude Code sessions are running, the hard part becomes keeping track of what each one is doing — and knowing where you need to step in.

  • 01

    Know what's happening

  • 02

    Keep approvals yours

    Permission requests are surfaced as visible cards. You decide what to allow; VibeDesk doesn't approve commands for you.

  • 03

    See the result in context

    Bring previews, terminal work and Git closer together instead of spreading the workflow across unrelated windows.

  • 04

    Carry context forward

    Keep project notes and decisions close so each new session has useful context to work from.

No small print

Questions, answered plainly.

The essentials before you download — including what's free and what isn't.

Is VibeDesk really free?

Yes. VibeDesk is open source under the MIT license. There is no VibeDesk subscription, trial period, paid tier or required account.

Do I still need Claude Code?

Yes. VibeDesk runs the official Claude Code CLI with your own access. Your Claude plan or API usage is separate and may cost money.

Is VibeDesk made by Anthropic?

No. VibeDesk is an independent project and is not affiliated with Anthropic.

What data does VibeDesk send?

The project documentation describes the app's network behaviour and privacy details. By default, update checks use GitHub; optional integrations only connect when enabled. Read the privacy notes in the README for the full details.

Which operating systems are supported?

VibeDesk is built for Windows 10 and Windows 11. macOS and Linux are not currently supported.

Can I inspect the code before installing?

Yes. Browse the repository, license and releases on GitHub.
