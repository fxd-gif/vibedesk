Your AI isn't the bottleneck.

Claude can read, change, test and reason about code. But when several sessions are running, you become the system that keeps them organised: switching terminals, spotting permission prompts, remembering context and checking what finished.

VibeDesk gives that work a home. It doesn't replace Claude Code. It gives you a clearer way to direct it.

Stay ahead of every session.

Every session has a status. Requests are visible. Results have somewhere to go. You stay the one making the calls.

Read the fine print.

It's reasonable to ask why something useful costs nothing. Here is what free does—and doesn't—mean.

So, what's the catch?

There is no VibeDesk subscription, paid tier, trial or feature paywall. The project is open source under the MIT licence. The trade-off is simple: VibeDesk organises Claude Code, but you bring and pay for your own Claude access if your plan or API usage requires it.

Does “€0” mean Claude is free too?

No. VibeDesk costs €0. Claude Code access and any Anthropic plan or API charges are separate. VibeDesk doesn't include Claude usage.

Does VibeDesk track me?

VibeDesk has no analytics or telemetry. It checks GitHub for updates, and connects to the selected audio stream while audio is playing. Optional integrations—such as Discord, Twitch, the phone companion and Vibe Lounge—connect when enabled. The README privacy section lists the network activity and local files in detail.

Is this made by Anthropic?

No. VibeDesk is an independent open-source project that runs the official Claude Code CLI. Claude is a trademark of Anthropic.

Does VibeDesk work on Mac or Linux?

Not currently. VibeDesk is built for Windows 10 and 11.

Why might Windows warn me?

The installer is not code-signed yet. SmartScreen can warn about installers that don't have an established reputation. Read the release notes and verify the SHA256 checksum before installing.

Where can I inspect the code?

The project is public on GitHub. You can review the code, read the MIT licence, report problems or build VibeDesk yourself.
